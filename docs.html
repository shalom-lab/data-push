BYOK 快速开始 模板格式 字段类型

BYOK（自带密钥）

Token 只写进当前浏览器的 localStorage，页面只向 api.github.com 发请求，没有自己的后端。Classic PAT 勾选 repo；Fine-grained PAT 给目标仓库 Contents: Read and write。

快速开始

  1. 打开设置，粘贴 Token 并验证。
  2. 在模板页按场景改字段，或导入原来的 JSON。
  3. 到推送页搜索仓库、选分支、填表、预览后提交。

模板格式

与原先扩展兼容：顶层是模板字典，每项包含 name、filename、fieldOrder、fields。

{
  "my-project": {
    "name": "我的项目",
    "filename": "data-raw/projects.json",
    "fieldOrder": ["title", "tags"],
    "fields": {
      "title": { "type": "text", "label": "名称", "required": true },
      "tags": { "type": "array", "label": "标签", "default": [] }
    }
  }
}

字段类型

  • text / textarea / url
  • select / radio（需要 options）
  • date / number / checkbox
  • array：回车或空格添加标签

提交时在对象上追加 timestamp，再写入仓库里的 JSON 数组。

BYOK

The token stays in this browser’s localStorage. Requests go only to api.github.com. Classic PAT: repo. Fine-grained PAT: Contents Read and write on the target repos.

Quick start

  1. Paste and verify a token in Settings.
  2. Edit templates visually or import the original JSON.
  3. On Push, pick a repo and branch, fill the form, preview, submit.

Template format

Compatible with the extension: a dictionary of templates, each with name, filename, fieldOrder, and fields.

{
  "my-project": {
    "name": "My project",
    "filename": "data-raw/projects.json",
    "fieldOrder": ["title", "tags"],
    "fields": {
      "title": { "type": "text", "label": "Title", "required": true },
      "tags": { "type": "array", "label": "Tags", "default": [] }
    }
  }
}

Field types

  • text / textarea / url
  • select / radio (need options)
  • date / number / checkbox
  • array: add tags with Enter or Space

Each submit appends an object (plus timestamp) to the JSON array in the repo.
